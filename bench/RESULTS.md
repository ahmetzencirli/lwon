# Token benchmark

Tokens counted with the o200k tokenizer (`gpt-tokenizer`), a proxy until Claude token counts are added.
Percentages are against **minified JSON**, the honest baseline. Generated by `npm run bench`.

| Dataset | Shape | JSON indented | JSON minified | TOON | LWON | LWON vs JSON | LWON vs TOON |
|---|---|--:|--:|--:|--:|--:|--:|
| users | Flat table, 100 rows | 5042 | 2942 | 1744 | 1649 | -44% | -5% |
| orders | Nested objects and arrays, 50 orders | 9226 | 5400 | 5753 | 3624 | -33% | -37% |
| issues | GitHub-style issues with nullable objects, 30 rows | 4607 | 2971 | 3526 | 2018 | -32% | -43% |
| menu | Recursive tree, 3 levels | 696 | 395 | 530 | 282 | -29% | -47% |
| logs | Log events with optional fields, 80 rows | 4522 | 3126 | 3619 | 2636 | -16% | -27% |
| search | Search tool result: object with a result list | 2722 | 1985 | 1608 | 1623 | -18% | 1% |
